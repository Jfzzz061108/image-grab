# 图提取 · 官网

「图提取 / ImageGrab」Chrome 电商图片提取下载插件的官方宣传网站，纯静态、无需构建工具、无需后端。

## 如何预览

直接双击打开 `docs/index.html`，即可在浏览器中查看完整官网。

## 目录结构

```
docs/
├── index.html       # 首页（产品介绍 + 核心功能 + 安装步骤 + CTA）
├── css/
│   └── style.css    # 全站样式（含响应式）
├── js/
│   └── main.js      # 交互脚本（菜单、导航高亮、滚动动画）
└── assets/          # 预留（当前示意图均为内联 SVG / 纯 CSS，无需外部图片）
```

## 如何修改

- **主色调**：修改 `css/style.css` 中 `:root` 里的 `--primary`（蓝）和 `--primary-2`（紫）两个变量，全站颜色会统一跟随变化。
- **文案**：直接编辑 `index.html` 中各区块的文字即可。
- **示意图**：Hero 区的插件界面示意图由纯 CSS 渐变色块模拟，可修改 `.g1` ~ `.g6` 的渐变或替换为真实截图（放入 `assets/` 后引用）。

## 页面区块（自上而下）

1. 顶部导航栏（吸顶毛玻璃 + 汉堡菜单）
2. Hero 首屏（主标题 + 双按钮 + 插件界面示意图）
3. 产品介绍（3 个问题卡片）
4. 核心功能（6 个功能卡片）
5. 安装步骤（4 步时间线）
6. 底部 CTA + Footer
