# 图提取 - 电商图片下载插件

一键提取淘宝、京东、拼多多商家版商品详情页的所有图片，集中预览、勾选，批量下载为 PNG。

## 文件结构

```
image-grab-extension/
├── manifest.json     # 扩展配置（Manifest V3）
├── content.js        # 注入右下角「获取图片」按钮 + 提取页面图片
├── content.css       # 按钮样式
├── background.js     # Service Worker：存储、打开画廊、统一下载
├── gallery.html      # 画廊页结构
├── gallery.css       # 画廊页样式
└── gallery.js        # 展示、勾选、转 PNG / 打包 ZIP 下载
```

## 安装步骤

1. 下载/解压本文件夹到本地（路径不要随意改名，加载后也不要移动）。
2. 打开 Chrome，地址栏输入 `chrome://extensions` 并回车。
3. 打开右上角的「开发者模式」开关。
4. 点击左上角「加载已解压的扩展程序」，选择本 `image-grab-extension` 文件夹。
5. 安装完成后，可在扩展栏看到「图提取」图标。

## 使用方法

1. 打开淘宝 / 京东 / 拼多多商家版的某个**商品详情页**。
2. 页面右下角会出现「获取图片」悬浮按钮，点击它。
3. 扩展会自动扫描并打开一个新的画廊页，网格展示所有商品图。
4. 在画廊页勾选想要的图片（支持全选 / 反选）。
5. 点击「下载 PNG」可把每张图单独保存为 PNG；点击「打包 ZIP」可把选中的图片打包成一个 `商品图_打包.zip` 压缩包。
6. 图片会统一转换为 PNG 并保存到浏览器默认下载目录，文件名形如 `商品图_001.png`。

## 说明与常见问题

- **按钮只在商品详情页显示**：其他页面不会注入按钮，避免干扰。
- **图片过滤**：自动过滤掉 logo、图标、占位图、小于 100×100 的图片。
- **权限说明**：`host_permissions` 使用了 `<all_urls>`，这是为了能跨域读取并下载各电商平台 CDN 上的图片（这些 CDN 域名不固定，例如 alicdn、360buyimg、pddpic 等）；而 `content_scripts` 的 `matches` 仍严格限定在三个电商平台，按钮不会注入其他网站。
- **下载失败**：个别图片可能因防盗链或网络问题失败，可刷新详情页后重试；若某平台经常失败，可查看该图片的实际域名，在 `manifest.json` 的 `host_permissions` 中补充。

## 修改主色调

画廊页和按钮的主色都使用渐变 `#4f7cff → #7a5cff`，可在 `gallery.css` 的 `:root` 变量与 `content.css` 中统一修改。
